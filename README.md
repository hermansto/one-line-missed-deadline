Entry for the make.fun competition **Funniest Excuse for a Missed Deadline**.

The line:

> The deadline moved. I was never told. I assumed it was a suggestion.

`main.ts` writes that exact line — 68 characters, no trailing newline — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/missed-deadline-out node main.ts
```
